# Vilra v0.2.1 — Alpha

Vilra is now available as an Electron desktop application for Linux x86-64 and Windows x64. This is an alpha release: keep backups of important files and report reproducible issues through GitHub.

## Highlights

- Local Electron runtime backed by Rust and SQLite; no external database or Python runtime is required.
- Multiple image libraries with safe disconnect behavior.
- Native batch tagging for selected images.
- Open Original and Reveal in Folder desktop actions.
- Corrected Viewer FIT geometry for portrait, landscape, and square images.
- Clearer first-run library selection and runtime error messages.

## Downloads

- `Vilra_0.2.1_amd64.AppImage` for Linux x86-64.
- `Vilra_Setup_0.2.1_x64.exe` for Windows x64.
- `SHA256SUMS.txt` for download verification.

The Windows installer is not code-signed, so Microsoft Defender SmartScreen may display a warning. Do not disable system security controls; verify the SHA-256 checksum and proceed only if you trust this release.

## Supported images

JPEG (`.jpg`, `.jpeg`), PNG (`.png`), and WebP (`.webp`).

## Known limitations

- Alpha software may still contain platform-specific defects.
- Windows installer and application binaries are unsigned.
- Thumbnail caches are stored in `.imgindex/thumbs` inside each connected library.
- A project license has not yet been selected by the owner.
